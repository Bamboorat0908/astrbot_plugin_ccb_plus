# astrbot_plugin_ccb_plus

> CCB 增强版 —— 基于 [灵煞 / ccb](https://github.com/Koikokokokoro/astrbot_plugin_ccb) 改进的 AstrBot 群娱乐插件
>
> ⚠️ 本插件为群友互动娱乐用途，请遵守当地法律法规及平台社区规范使用。

## ✨ 玩法简介

在群里 @ 群友进行一场紧张刺激的 **ccb**（插件核心玩法）。系统会基于连击、暴击、绝顶、养胃、挣脱等一系列概率机制生成随机文案反馈，并长期记录每一位群友的"战绩"。

- **核心指令** `ccb [@某人]`：对目标发起 ccb，未 @ 时默认对象取决于配置
- **强制指令** `qzccb [@某人]`：无视绝顶冷却，100% 触发绝顶与长文案
- **群开关** `ccbswitch on/off`：管理员可随时禁用/恢复本群 ccb 功能

## 🎮 玩法机制

| 机制 | 说明 |
| ---- | ---- |
| 🥒 养胃限流 | 连续 ccb 会触发逐级递进的"养胃"概率，炸膛后一段时间内无法再 ccb；超过重置时间未操作则连续计数清零 |
| 💦 绝顶 | ccb 命中后有概率触发绝顶，触发后目标进入约 30 分钟的绝顶冷却 |
| 🔥 连击系统 | 同一对对象在 30 分钟内连续 ccb 形成连击，连击达到 3 / 5 / 7 档会提升绝顶概率并解锁更长的文案演出 |
| 💥 暴击 | 按配置概率触发暴击，注入量翻倍 |
| 🏃 挣脱 | ccb 时目标有小概率挣脱成功（针对特定对象设有专属挣脱机制） |
| 🛡️ 白名单 | 白名单内对象受保护，无法被 ccb |
| 🏆 成就系统 | 达成条件自动解锁成就，支持群内播报 |

## 🏆 成就列表

| 成就 | 图标 | 解锁条件 |
| ---- | ---- | -------- |
| 初体验 | 🐣 | 第一次 ccb 成功 |
| 连击大师 | 🔥 | 连击数达到 7 |
| 绝顶高手 | 💀 | 累计让别人绝顶 20 次 |
| 绝顶杂鱼 | 🧹 | 累计被绝顶 10 次 |
| 征服者 | 💪 | 累计 ccb 成功 50 次 |
| 永动机 | ♾️ | 连击 ≥3 时触发"再战" |
| 全成就 | 🌟 | 解锁以上全部成就 |

## 📋 命令列表

| 命令 | 说明 |
| ---- | ---- |
| `ccb [@]` | 对目标 ccb（核心玩法） |
| `qzccb [@]` | 强制 ccb，100% 绝顶 + 长文案 |
| `ccbswitch on/off` | 开关本群 ccb 权限（需管理员） |
| `ccbtop` | 按 ccb 次数排行 |
| `ccbvol` | 按注入量排行 |
| `ccbclimax` | 按绝顶次数排行 |
| `ccbmax` | 按单次最大注入量排行（含产生者） |
| `ccbinfo` | 查询个人 ccb 档案 |
| `ccbachieve [@]` | 查看 ccb 成就 |
| `ccbtoday` | 查看今日 ccb 日报（过去 24h，含海王 / 小南梁等） |
| `ccbreport` | 生成本群统计报告图片 |
| `ccbglobal` | 生成跨群全局统计报告图片 |
| `xnn` | XNN 榜 |

> 说明：原「海王榜」`haiwang` 命令根据群友使用量反馈已被注释停用。

## ⚙️ 配置项

| 配置项 | 类型 | 默认值 | 说明 |
| ------ | ---- | ------ | ---- |
| `yw_ban_duration` | int | `3600` | 养胃时长（秒），触发限流后禁用的时长 |
| `yw_reset_timeout` | int | `300` | 连续 ccb 计数重置时间（秒） |
| `white_list` | list | `[]` | 不能进行 ccb 的 id 列表（受保护对象） |
| `self_ccb` | bool | `false` | 是否允许 0721（ccb 未指定对象时对自己施放） |
| `crit_prob` | float | `0.2` | 暴击概率（注入量翻倍） |
| `is_log` | bool | `false` | 是否独立保留每一条 ccb 完整记录 |

配置可在 AstrBot 管理面板的插件配置页中修改。

## 💾 数据存储

- **主数据文件**：`data/ccb.json` —— 按群保存次数、注入量、max、成就等长期数据
- **完整日志**：`data/ccb_log.json` —— 当 `is_log` 开启时记录每一条 ccb 明细

> 更新插件前建议备份数据文件，以防旧数据格式不兼容导致异常。

## 🚀 安装

### 方式一：AstrBot 插件市场

1. 打开 AstrBot 管理面板 → 插件管理
2. 搜索 `astrbot_plugin_ccb_plus` 并安装
3. 重载插件，在配置页调整参数后即可使用

### 方式二：手动安装

```bash
cd <AstrBot>/data/plugins
git clone https://github.com/Bamboorat0908/astrbot_plugin_ccb_plus.git
```

本插件无额外 Python 依赖，安装后重载即可开箱即用。
